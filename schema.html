Question Bank Schema

The Exam Simulator accepts valid JSON files containing an array of question objects. You can create your own files or use Generative AI to produce new batches.

Data Structure

Key Type Description
id number Unique identifier for the question (e.g., 1, 102).
question string The full text of the exam question.
options string[] Array of 4 or 5 possible answer strings.
answer string[] Array containing the correct option(s). Must match text in options exactly.
type string Either "single_choice" or "multiple_response".
domain string Exam domain (e.g., "Security and Compliance").
explanation string Detailed text explaining why the answer is correct.

JSON Example

[
  {
    "id": 101,
    "question": "Which AWS service is used to govern your environment?",
    "options": [
      "AWS Config",
      "AWS OpsWorks",
      "Amazon S3",
      "Amazon EC2"
    ],
    "answer": ["AWS Config"],
    "type": "single_choice",
    "domain": "Management and Governance",
    "explanation": "AWS Config enables you to assess, audit, and evaluate configurations."
  }
]

AI Generator Prompt

Copy the prompt below and paste it into ChatGPT, Claude, or Gemini to generate new, valid question batches instantly.

Create 50 high-quality practice questions for the AWS Certified Cloud Practitioner (CLF-C02) exam.

**Output Format:**
Provide a single, strictly valid JSON array of objects. Do not wrap in markdown code blocks.

**Schema Requirements:**
1. "id": Unique integer (start from 1).
2. "question": The question text.
3. "options": Array of 4-5 distinct string choices.
4. "answer": Array of strings containing the correct option(s). Text must match "options" exactly.
5. "type": String, either "single_choice" or "multiple_response".
6. "domain": String (e.g., "Cloud Concepts", "Security and Compliance", "Billing", "Technology").
7. "explanation": A detailed string explaining the correct answer.

**Content Requirements:**
- Focus on CLF-C02 specific topics: Cloud Adoption Framework (CAF), Well-Architected Framework, Migration Strategies (7 Rs), and newer AI services (Bedrock, Q, CodeWhisperer).
- Ensure a mix of 70% single choice and 30% multiple response questions.
- Avoid deprecated services.
